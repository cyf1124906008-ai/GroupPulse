# GroupPulse 使用说明

## 导入与更新

1. 完整解压安装包并打开 GroupPulse，在首页选择“导入本机记录”。
2. 选择账号目录、`db_storage` 或完整明文副本。必须同时有 `session/session.db`、`contact/contact.db` 和消息分库。
3. 明文副本可直接读取；加密库需要有效的 64 字符十六进制数据库密钥。密钥只填进软件，不发到聊天、Issue 或日志中。
4. Mac 的“初始化本机密钥”会先提示手动退出微信；经你确认后，准备临时登录副本，需本人扫码或确认登录，不修改原版应用。临时文件约需 1.1 GB，结束后清理。微信或系统版本变化可能导致初始化不可用，可改用已有合法取得的密钥。
5. Windows 的 `.keyinfo` 必须由同一 Windows 用户、同一系统的 DPAPI 解密。软件不捆绑 ChatTrace，不能拿其他人的文件直接使用。
6. 账号原始 ID 可填写有依据的 WXID；不确定可留空。软件不通过昵称猜测本人身份。图片未显示时，在设置中选择账号原媒体目录。
7. 用“立即同步”刷新数据。自动同步每分钟检查一次源数据库变化；本机未保存或尚未被微信加载的内容不会出现。静态明文副本不会自己变成实时源。

第一次会复制数据库并建立索引，大数据量需要时间和额外磁盘空间；同步阶段有进度和停止按钮。导入失败保留上一份已成功的索引。快照、索引和媒体缓存存放在系统应用数据目录的 `GroupPulse` 下，含私人信息，不要上传整个目录。

## 搜索与发送者定位

- 群聊搜索可选群、日期、发送者和消息类型；搜索按钮与回车都可提交。普通检索多个词用逗号分隔，再选“任一”或“全部”。
- 长消息先显示关键词附近的句子，点展开可看全文。聊天、朋友圈、通讯录的文字命中均高亮。
- 点“定位完整原文”，核对群名、时间、WXID、微信号、昵称、备注、分库和本地 ID；点“查看聊天上下文”进入该会话前后记录。
- 本机没有微信号、头像或真实发送者字段时，会标注缺失。不同 WXID 即使昵称相同也不会合并。

## 群聊分析、供需与报价

- 群聊分析提供消息量、词频、日期 / 小时分布、自定义关键词。消息数、词语出现次数、群数、发送者数分别统计。
- 供需整理选择近 1 / 3 / 6 / 24 小时，以及全部群或选定群。搜索词空格 / 逗号分隔，按全部命中；屏蔽词任一命中即排除。配对任一方被排除则整对隐藏。
- 相同发送者的相同正文合并，来源列表保留所有重复出现；不同发送者不会因同文而合并。混合供需或证据不足的内容待核对。
- 报价区分别统计折扣、每刀单价、明确倍率、套餐档位与按周期金额。商品与单位不同的数字不会直接平均。搜索、数值范围、发送者和排序可组合使用。
- 供需和报价来自规则识别，可能漏掉隐晦表达或误判；它们是原文线索，不是成交记录或投资建议。

## 图片、语音与朋友圈

本机头像来自头像数据库，消息媒体通过资源索引定位；DAT 图片本机解码，SILK 转为可播放 WAV，MP4 支持定位播放。WXGF 通过随附独立 FFmpeg 解码为首帧；可在设置中自行选择兼容的外部 FFmpeg。动画不保证完整恢复。

朋友圈只显示本机缓存内容。远程媒体下载默认关闭，开启后仅允许固定腾讯媒体域名，不保证过期资源可下载。缺失、删除或未缓存内容不会被伪装成已恢复。

## 模型 API

在设置填写服务地址、模型名称、接口格式和 API Key。服务地址通常以 `/v1` 结尾，Google 常用 `/v1beta`；本机服务可用 `http://localhost`，云端要求 HTTPS。模型密钥由本机系统保护保存，不返回前端。

在群聊分析输入问题，先点击检查摘录与发送范围，再核对目标、模型、样本数量与字符数。确认后发送；原生确认窗口默认取消。AI 最多使用 60 条最新匹配摘录，每条最多 1,000 字符；并不代表全部历史。模型服务可能计费，结论应依据 [E001] 等来源编号核查。

## 导出、外观与应用锁

CSV / JSON 导出遵循当前筛选，包含全部匹配记录；导出不受页面折叠、显示条数或高亮影响。年度报告可保存为独立 HTML。CSV 会处理公式前缀，降低直接打开表格时误执行的风险。

右上角切换中英文，不重启应用；设置可选浅色 / 深色 / 跟随系统。应用锁至少 6 位，保护界面访问。它不加密硬盘上的快照或导出；若忘记应用锁密码，软件没有远程找回服务。
