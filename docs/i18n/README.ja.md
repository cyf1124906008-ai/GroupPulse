# GroupPulse

**グループの会話を検索し、出典を確かめ、情報を整理する。**

[中文](../../README.md) · [English](README.en.md) · 日本語

GroupPulse は、PC 内に保存された WeChat 4.x の記録を扱う独立したデスクトップアプリです。チャット、モーメンツ、連絡先を検索し、キーワードの頻度、需要と供給、価格の手がかりを整理できます。結果から送信者と元のメッセージ、その前後の会話を確認できます。

![概要](../screenshots/overview-en.png)

## 主な機能

- 検索ボタンと Enter キー、検索語のハイライト、長文の一致箇所を優先したプレビュー。
- グループ別の発言数、日別・時間別の活動、単語頻度、独自キーワードの集計。
- 1・3・6・24 時間の需要・供給整理。同一送信者の重複投稿をまとめ、すべての出典を保持。候補の組み合わせは成約を意味しません。
- 割引、CNY/USD 単価、明示的な倍率、プラン表示、期間別金額を区別した価格統計。
- ローカル画像、アバター、SILK 音声、MP4、WXGF の最初のフレームを表示。未保存・削除済みの資料は復元を保証しません。
- 自分のモデル API を使う任意の AI 分析。送信先と抜粋を確認してから送信し、サービスの利用料が発生する場合があります。
- 絞り込みに従う CSV / JSON の全件出力、HTML 年次レポート、ブックマーク。

## 利用と制限

[リリース](https://github.com/cyf1124906008-ai/GroupPulse/releases/latest)から macOS Apple Silicon または Windows x64 版を取得してください。完全に解凍し、Mac では GroupPulse.app、Windows では GroupPulse/GroupPulse.exe を開きます。ローカルのアカウントフォルダまたは完全な平文コピーを選択します。暗号化データには正しいローカル鍵が必要です。

元のデータベースは読み取り専用です。静的コピーからサーバーの履歴が自動取得されることはありません。UI は**簡体字中国語と英語**に対応し、日本語 UI はまだありません。画像は合成デモで、実際の会話ではありません。
